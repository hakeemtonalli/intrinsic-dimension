# intrinsic-dimension
Intrinsic Dimension Estimation


## Setup
```
conda create -n intrinsic-dimension python=3.12
conda activate intrinsic-dimension
pip install pandas matplotlib seaborn youtube-comment-downloader scikit-dimension 
pip install torch==2.7.0 torchvision==0.22.0 torchaudio==2.7.0 --index-url https://download.pytorch.org/whl/cu118
pip install transformers 
```

## Run
```
python main.py
```
